# Personal Portfolio Website

My personal portfolio website, built to show who I am, what I know and the projects I have made.

**Live site:** https://malikrizwann9988-pixel.github.io/PORTFOLIO/

## Sections
- About Me
- Skills (HTML, CSS, JavaScript, Git, GitHub)
- Projects
- Education
- Contact links in the footer

## Built with
- HTML5
- CSS3 (Grid, Flexbox, smooth scrolling navigation)
- Hosted on GitHub Pages

## Status
Desktop layout is complete. Mobile layout is still in progress.

## Run it locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
